# Remote Mouse Jiggler Website

Official web portal, feature showcase, privacy policy, and terms of service for the **Remote Mouse Jiggler** Android application.

Turn your smartphone into a Bluetooth wireless mouse, touchpad, TV remote, presentation controller, and automated mouse jiggler.

## Features
- **Zero Software on Computer**: Connects via standard Bluetooth HID profile out of the box.
- **7-Pattern Mouse Jiggler**: Micro Jitter, Smooth Circle, Figure 8, Random Wander, Wave, Expanding Spiral, Diagonal Bounce.
- **Touchpad & Gyroscope Air Mouse**: Precision pointer controls with motion sensing.
- **D-Pad & Android TV Navigation**: Complete remote control for smart TVs and media boxes.
- **Media & Shortcuts**: Volume, playback controls, and multi-language virtual keyboard.
- **100% Private**: No internet connection needed, zero telemetry or tracking.
